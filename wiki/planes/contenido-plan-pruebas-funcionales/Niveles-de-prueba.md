# Niveles de Prueba

En esta etapa, el enfoque será el siguiente:

*   **Pruebas Unitarias:** Ejecutadas automáticamente durante la construcción del proyecto por los desarrolladores. Verifican funciones y métodos aislados.
*   **Pruebas de Integración:** Evaluaremos la comunicación entre el frontend (Angular) y los endpoints del backend (Spring Boot), así como la integración con la base de datos (PostgreSQL).
*   **Pruebas de Sistema:** Ejecución de casos de prueba funcionales en el sistema ensamblado en el entorno de pruebas, simulando interacciones del usuario final de extremo a extremo (End-to-End).
