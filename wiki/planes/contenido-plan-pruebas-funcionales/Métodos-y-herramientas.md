# Métodos y Herramientas

**7.1 Gestión y Planificación**
*   **Gestión de tareas, casos de prueba y defectos:** GitHub Issues (empleando templates estandarizados) y GitHub Projects para visualización en tablero Kanban.
*   **Documentación de Pruebas:** GitHub Wiki del repositorio para el mantenimiento de este plan de pruebas y documentación relacionada.

**7.2 Desarrollo y Calidad de Código**
*   **Análisis estático Backend:** Checkstyle para código Java.
*   **Análisis estático Frontend:** Biome (linter y formateador) para código del cliente.

**7.3 Automatización e Integración Continua**
*   **CI/CD:** GitHub Actions para ejecución automática de pruebas unitarias y linters en cada Pull Request.
*   **Reportes de Cobertura:** Herramientas como JaCoCo (backend) y herramientas de cobertura de Jest/Vitest (frontend) integradas en el pipeline de GitHub Actions.
